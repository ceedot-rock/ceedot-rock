# Contributing to ceedot-rock/ceedot-rock

This is the GitHub profile repository for **Corey Tasz / Slid Phi Labs**.
Its only user-visible content is `README.md` — the profile page. The
following rules keep it accurate.

## What changes are welcome

- Fixing broken links, typos, or outdated project information.
- Suggesting wording improvements that keep every claim verifiable.

Anything else — new products, design changes, contact details — goes
through Corey first; open an issue to propose it.

## Process

1. Fork the repo and open a pull request against `main`.
2. Use the pull request template. Check that every link resolves.
3. Preview your change: GitHub renders the profile README only on the
   owner's profile, so attach a screenshot of the rendered README
   (e.g. from your fork's README page) if the change affects layout.

## Ground rules

- No claims that aren't verifiable elsewhere (product pages, repos).
- No personal information, credentials, or secrets — ever.
- Keep it short: this is a profile page, not a website.
