# Security Policy

This repository contains only the GitHub profile page for
**Corey Tasz / Slid Phi Labs** — there is no code, no dependencies, and no
running service, so there is no traditional attack surface here.

What *is* a security concern for this repo:

- Impersonation: profile content altered or forked to misrepresent Corey
  or Slid Phi Labs.
- Phishing or scam links introduced into the profile (e.g. a fake contact
  or "support" link that replaced a legitimate one).
- Spoofed contact details that do not match the verified ones on
  slidphilabs.com.

## Reporting a concern

Please do not open a public issue for security concerns.

- Email: corey@slidphilabs.com with the subject line `Profile security`
- Or use GitHub's private vulnerability reporting on this repository
  (Security tab, "Report a vulnerability")

You can expect an acknowledgement within 3 business days, and credit in the
commit message unless you prefer to stay anonymous.
